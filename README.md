### 🚀 Featured Projects

#### 🔐 [UPI Offline Mesh — Peer-to-Peer Offline Payment System](https://github.com/Priyanshu-010206/upi-offline-mesh)

> Spring Boot simulation of offline UPI payments via Bluetooth-style mesh networking

- 🔒 Hybrid **RSA-OAEP + AES-256-GCM** encryption for end-to-end secure payments
- ⚡ Atomic idempotency layer using ConcurrentHashMap to prevent duplicate settlements
- 🛡️ Replay attack prevention via SHA-256 hashing + UUID nonce deduplication
- 📡 Virtual mesh simulator with gossip-protocol propagation & TTL-based routing
